# SideProjectManager

어떤 토이·사이드 프로젝트에서도 쓸 수 있는 무료 업무 도구 모음입니다.

| 도구 | 하는 일 | 상태 |
| --- | --- | --- |
| [local-hub](local-hub/) | 클라우드 없이 공용 PC 한 대에 공통 서비스(DB 등)와 팀원 서비스를 띄우고, git 에 새 커밋이 올라오면 자동으로 다시 빌드·재기동 | 사용 가능 |
| 일정·할 일 자동 관리 | GitHub Issues + Projects + Actions 로 이슈 정리, 마감 알림, 주간 요약 | 예정 |
| 프로젝트 템플릿 | 위 도구를 새 프로젝트에 바로 복사해 쓰는 템플릿 | 예정 |

모든 도구는 유료 서비스 없이 동작하는 것을 원칙으로 합니다.
